## Code Review Methodology
1. Review syntax and structure for readability and PEP 8 compliance.
2. Check for security vulnerabilities: SSRF, SQL/command injection, unescaped shell calls.
3. Validate error handling, timeouts on network calls, and resource cleanup.
4. Output concise bullet points with line references and actionable improvements.
